P4-2: Operator precedence table with auto-parenthesization
============================================================

Implementation:
- Added c_precedence(op: IrOp) -> u8 mapping all binary IrOps to C precedence levels:
  70: Call/Callind, 62: unary prefix, 54: mult/div/mod, 50: add/sub,
  46: shifts, 42: relational, 38: equality, 34: bitwise AND, 30: XOR,
  26: bitwise OR, 22: logical AND, 18: logical OR, 0: default
- Added is_binop() helper for identifying binary operator ops
- Split emit_expr into emit_expr + emit_expr_with_prec (parent_prec threading)
- Modified emit_binop to accept parent_prec; wraps output in parens when
  child precedence < parent precedence
- Modified emit_unaryop to pass its own precedence (62) as parent_prec to
  operand, ensuring binary operands get parenthesized
- Replaced emit_operand_with_context with emit_operand_with_prec that threads
  parent_prec through to folded inline expressions
- Removed unconditional parens wrapping (old: always `format!("({})", inner)`)
  in favor of precedence-aware wrapping

Tests added (5):
- test_parens_shift_in_add: (a << b) + c — shift(46) < add(50) → parens
- test_parens_add_in_multiply: (a + b) * c — add(50) < mult(54) → parens
- test_no_parens_same_prec_assoc: a + b + c — same prec → no parens
- test_parens_nested_binop: (a | b) & c — OR(26) < AND(34) → parens
- test_parens_unary_on_binop: -(a + b) — unary(62) > add(50) → parens

Also fixed pre-existing P4-1 issues:
- Added missing emit_unsigned_binop function (was referenced but undefined)
- Added missing unsigned_cast function
- Fixed test_signed_div_no_cast assertion (was matching typedefs containing "unsigned")
- BoolXor now correctly emits "^" (was "!=")
