P4-5: Signed/unsigned operator distinction
==========================================

Changes:
- IntDiv (unsigned) now emits: `(unsigned __int32)a / (unsigned __int32)b`
- IntSdiv (signed) still emits: `a / b` (no cast)
- IntRight (logical shift) now emits: `(unsigned __int32)a >> b` (LHS only)
- IntSright (arithmetic shift) still emits: `a >> b` (no cast)
- IntLess (unsigned) now emits: `(unsigned __int32)a < (unsigned __int32)b`
- IntSless (signed) still emits: `a < b` (no cast)
- IntLessequal (unsigned) now emits: `(unsigned __int32)a <= (unsigned __int32)b`
- IntSlessequal (signed) still emits: `a <= b` (no cast)
- IntRem (unsigned) now emits: `(unsigned __int64)a % (unsigned __int64)b`
- IntSrem (signed) still emits: `a % b` (no cast)

Implementation:
- Added `emit_unsigned_binop()` helper that wraps operands with `type_for_size(sz, false)`
- For `>>`, only the LHS is cast (shift amount doesn't need unsigned cast)
- Uses `ConstContext::Bitwise` for constant rendering in unsigned ops

Tests added (8):
- test_unsigned_div_cast: IntDiv → `(unsigned __int32)v1 / (unsigned __int32)v2`
- test_signed_div_no_cast: IntSdiv → `v1 / v2` (no unsigned)
- test_unsigned_shift_cast: IntRight → `(unsigned __int32)v1 >> v2`
- test_signed_shift_no_cast: IntSright → `v1 >> v2`
- test_unsigned_less_cast: IntLess → `(unsigned __int32)v1 < (unsigned __int32)v2`
- test_signed_less_no_cast: IntSless → `v1 < v2`
- test_unsigned_rem_cast: IntRem → `(unsigned __int64)v1 % (unsigned __int64)v2`
- test_unsigned_lessequal_cast: IntLessequal → `(unsigned __int32)v1 <= (unsigned __int32)v2`
