P4-6: Expand compound assignment operators
==========================================

STATUS: DONE

Changes in crates/unlace-output/src/c_printer.rs:
- try_emit_compound_assign expanded from 2 ops (+=, -=) to all 10 C compound operators:
  +=, -=, *=, /=, %=, <<=, >>=, &=, |=, ^=
- Operator map:
  IntMult → *=, IntDiv/IntSdiv → /=, IntRem/IntSrem → %=,
  IntLeft → <<=, IntRight/IntSright → >>=,
  IntAnd → &=, IntOr → |=, IntXor → ^=
- Commutativity: +=, *=, &=, |=, ^= accept either operand position
  Sub, div, mod, shifts require output==inputs[0]
- emit_statement now applies compound assign (not just emit_for_clause)
- Foldable input guard: compound assign suppressed when counter operand
  has inline-folded definition (prevents `((1) + 2) += 3` malformation)
- Bitwise context: &=, |=, ^=, <<=, >>= use ConstContext::Bitwise
  so hex masks are preserved (e.g. `v1 &= 0xfffffffcULL` not `v1 &= -4`)
