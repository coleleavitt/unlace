P3-1: Compiler Division Idiom Recovery
=======================================

TASK: Recognize (x * magic_constant) >> shift as x / N for integer division.

FILES CHANGED:
  - NEW: crates/unlace-passes/src/division_idiom.rs (DivisionIdiomPass)
  - MOD: crates/unlace-passes/src/lib.rs (pub mod + pub use)

PASS IMPLEMENTATION:
  - DivisionIdiomPass implements Pass trait
  - Unsigned: INT_RIGHT(INT_MULT(x, magic), shift) -> INT_DIV(x, N)
  - Signed: INT_SRIGHT(INT_MULT(x, magic), shift) -> INT_SDIV(x, N)
  - Divisor recovery: N = round(2^shift / magic), verified over test vectors
  - Commutative: handles magic as either first or second multiply input
  - Dead multiply replaced with COPY for DCE cleanup

MAGIC CONSTANT EXAMPLES (32-bit unsigned):
  - div 3:  magic=0xAAAAAAAB shift=33
  - div 5:  magic=0xCCCCCCCD shift=34
  - div 7:  magic=0x24924925 shift=32
  - div 10: magic=0xCCCCCCCD shift=35

MAGIC CONSTANT EXAMPLES (32-bit signed):
  - sdiv 3: magic=0x55555556 shift=32
  - sdiv 5: magic=0x66666667 shift=33
