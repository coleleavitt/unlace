# Structuring rest on origin/master vs main (unlace-struct, minus structurer/)

Scope: `crates/unlace-struct/src/` on archived `origin/master` (3aaf121866), excluding `structurer/` and the files
already covered in `notes/orig-unlace/struct-structurer.md` and `notes/orig-unlace/struct-conditions-switch.md`
(irreducible, node_split, condition_refinement, reaching_conditions, switch_recovery, if_to_switch, short_circuit).
Main status is read on `origin/main` (88645838b2); line numbers are on the stated ref. Read-only: nothing was built or run.
Main has a different IR (Funcdata and the ctree printer, not HIR), so a "missing" row means no equivalent was found by name
and by reading the cited main file; each "partial" row names what main does cover.

Sizes: S under about 300 lines of master source, M 300 to 1,000, L over 1,000. The archive's own tests are not counted.

## Already on main (no port needed)

- Compound assignment: the printer emits `x OP= y` by default (`crates/unlace-emit/src/p9_emit/printc.rs:7951`, `PLUSEQUAL` at `printc.rs:260`). Master's `compound_assign.rs:30` is a HIR pass with the same effect.
- While to for: `analyzeforloops` (`phases.toml:599`, `:765`) covers `while_to_for.rs:11`.
- Eager returns, tail duplication and cross-jump reversal: `returndup.rs`, `earlyreturn.rs`, `taildup.rs`, `crossjumpreverter.rs` (SAILR family, `gotoreduce.rs` header). Covers `eager_returns.rs:14`, `tail_duplication.rs:47`, `cross_jump_revert.rs:21`.
- Return merge: `earlyreturn.rs`, `retsplitglobal.rs` cover `return_merge.rs:22`.
- Block merge: CollapseStructure's block collapse covers `block_merge.rs:33`.
- Goto to break and continue, and continue and break: `loopbreak_recovery.rs` and `loopcontinue.rs` cover `goto_to_break.rs:7`, `goto_to_continue.rs:7`, `continue_break.rs:19`.
- Label fallthrough: `gotonext.rs` covers `label_fallthrough.rs:21`.
- Loop rotation reversal: `looprotate.rs` and `guardedloop.rs` cover `loop_normalize.rs:36`.

## Skipped

- `hir_licm.rs:51` (loop-invariant code motion on HIR): the compiler has already hoisted, and source rarely hoists by hand, so hoisting adds lines that are not in the source.
- `loop_classify.rs`, `goto_classify.rs`: diagnostic counters.
- `region_bridge.rs`, `region_splice.rs`: DREAM steps 3a and 3b. Already covered in `notes/orig-unlace/struct-conditions-switch.md` row 1; they depend on the reaching-condition engine main lacks.
- `irreducible.rs`, `node_split.rs`: covered in `notes/orig-unlace/struct-structurer.md` row 4.
