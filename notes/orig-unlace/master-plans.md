# Ported techniques from the archived master planning docs

Read-only comparison. Nothing was built or run. The sources are origin/master ROADMAP.md, PHILOSOPHY.md, ARCHITECTURE.md, plan.md, learnings.md, ideas, and LUMINA_V6_HANDOFF.md, read with git show. Main is origin/main at 517a594ef9. Every "missing" entry is a grep over crates/ (and docs/spec where it applies) on that commit, excluding tests and fixtures, so a hit in a fixture or a comment does not count as support.

Out of scope and left out on purpose: MCP, the debugger, the emulator, LSP, and hand-written lifters. Rows already in archived-master-inventory.md are cross-referenced, not repeated (anti-debug is row 4 there). Sizes: S is under 300 lines of master code, M is 300 to 800, L is larger or cross-cutting.

## Method and limits

- Master code was read with git show and git grep against origin/master only. Nothing was checked out.
- The main grep is a keyword search, so a "missing" verdict means no matching code under crates/. A technique can still exist under another name. Rows 4 and 15 in particular should be confirmed by reading code before porting.
- Master code was not compiled or run, so the master descriptions are from the source and its doc comments.
