Detection Logic:
  Entry block (prologue):
    1. Frame pointer setup: STORE(addr, RBP) + RSP = RSP - 8 (push rbp)
    2. mov rbp, rsp: COPY(RSP) -> RBP or INT_ADD(RSP, 0) -> RBP
    3. Stack allocation: RSP = RSP - const_N (sub rsp, N)
    4. Callee-saved pushes: STORE(addr, Rxx) + RSP -= 8 for R15/R14/R13/R12/RBX
    5. Stack canary: LOAD with const 0x28 + subsequent STORE

  Exit blocks (epilogue):
    1. Frame pointer restore: RSP = COPY(RBP) + RBP = LOAD(addr) + RSP += 8
    2. Standalone pop rbp: RBP = LOAD(addr) + RSP += 8
    3. Callee-saved restores: REG = LOAD(addr) + RSP += 8 for callee-saved regs
    4. Stack deallocation: RSP = RSP + N

Suppression:
  Instructions are NOT removed from IR.
  Marked in SsaFunction::frame_setup_insns as BTreeSet<(BlockId, usize)>.
  Structurer skips marked instructions before they become HirNode::Statement.
  All 5 HirNode::Statement emission points in structurer.rs are filtered.
