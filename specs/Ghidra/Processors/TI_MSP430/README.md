# TI MSP430

Vendored from Ghidra. Local changes (unlace):

- Per-family languages `TI_MSP430:LE:16:<family>` (f1xx, f2xx, g2xx, f4xx, i2xx) and
  `TI_MSP430X:LE:32:<family>` (f5xx, f6xx, fr2xx, fr5xx, fr6xx) in `TI_MSP430.ldefs`, on the existing
  `.sla` files, each with a pspec `TI_MSP430_<family>.pspec` that labels the family's peripheral
  registers. The pspecs are generated by `tools/gen_msp430_pspec.py` from TI's MSP430 GCC support
  files 1.212 (`msp430-gcc-support-files-1.212.zip`, BSD-3-Clause; the notice is in
  `LICENSE-TI-MSP430-support-files.txt`). The `default` languages and `TI_MSP430.pspec` are unchanged.
