CRITICAL ANALYSES FOR DECOMPILER (10 MUST-HAVE)
================================================================================

1. DominatorTree / PostDominatorTree
   - Computes: Dominance relationships
   - Decompiler use: Control-flow structuring, immediate dominators
   - Status: Already implemented in unlace-struct

2. LoopInfo
   - Computes: Natural loop detection and hierarchy
   - Decompiler use: Loop recovery, loop nesting
   - Status: Already implemented

3. ScalarEvolution
   - Computes: Symbolic expressions for scalar values in loops
   - Decompiler use: Induction variable analysis, trip count computation
   - Status: Needs full implementation

4. CallGraph
   - Computes: Module-level call graph with external nodes
   - Decompiler use: Function call relationships
   - Status: Already implemented

5. MemorySSA
   - Computes: SSA form for memory operations (MemoryDef, MemoryUse, MemoryPhi)
   - Decompiler use: Memory SSA form, critical for memory analysis
   - Status: Partially implemented in unlace-ir

6. AliasAnalysis
   - Computes: Generic alias analysis interface (MustAlias, MayAlias, NoAlias)
   - Decompiler use: Pointer disambiguation, memory access analysis
   - Status: Needs improvement

7. ValueTracking
   - Computes: Properties of values (known bits, sign, range, etc.)
   - Decompiler use: Value property inference
   - Status: Partially implemented

8. InstructionSimplify
   - Computes: Simplifies instructions without creating new ones
   - Decompiler use: Expression simplification
   - Status: Partially implemented

9. ConstantFolding
   - Computes: Folds constant expressions
   - Decompiler use: Constant folding
   - Status: Partially implemented

10. TargetLibraryInfo
    - Computes: Library function signatures and properties
    - Decompiler use: Function signature database
    - Status: Needs implementation
