# Original unlace: c_printer, first half (origin/master)

Slug `output-cprinter-a`. Scope: `crates/unlace-output/src/c_printer/` on `origin/master`, files 1 to 20 of the sorted list: `cpa/{build,linear,mod,object,scale}.rs`, `mem_objects/{decl,mod,path}.rs`, `member_path.rs`, `mod.rs` (the 18,869-line printer, read by signature and by the sections that bear on pointer and member printing, not in full), `postprocess/combine/{lex,mod,parse,print,rules,tests}.rs`, and `postprocess/dead_assign/{driver,liveness,mod,pass}.rs`. Files 21 to 41 are in `notes/orig-unlace/output-cprinter-b.md`.

The original printer prints from a typed-pointer model and then rewrites the text. Main prints from a structured HIR through a Ghidra-port cast and pointer layer (`crates/unlace-emit/src/p9_emit/castarith.rs`, `crates/unlace-bandb/src/p3_dataflow/ruleaction_5.rs`, `crates/unlace-middle/src/substrate/addtreestate.rs`), so most of the address-shape work in `cpa/` is already on main. Searches cover `crates/**/*.rs`, not only the emit crate. The table keeps only what main lacks or only partly has. Checked on `origin/main` with `git grep`, file:line on main refers to that ref, and line numbers on master to `origin/master`. Status was judged from the code, not from header comments.

## Superseded, not ported

- `postprocess/dead_assign/*` (`driver.rs:46` cond-family gate, `:93` OF/PF flag idiom, `liveness.rs:55` loop-carried store, `:126` backward-goto liveness) and the text-level pruner in `pass.rs`: these exist only because the printer has no CFG and prunes text. Main runs `ActionDeadCode` on the IR (`crates/unlace-decomp/src/infra/universalaction.rs:1468` and `:1527`), so the flag and loop cases go away before printing. Grep for `__OFSUB__` and `__OFADD__` in `crates/unlace-emit` finds nothing.
- `postprocess/combine/parse.rs` and `print.rs`: a parse-and-reprint gate that rewrites a line only when the reprint matches the input. Main has no text rewriting to guard, so the gate has no job there.
- `mod.rs` cot coverage audit (the table at the top of the file): a checklist written against the older model. Its status column is not evidence for main.

## Notes for whoever ports

- Rows 1 to 4 share one design question: which type model the typed-pointer and object rewrites read (Ghidra `Datatype` on main, the original's synthesised `Type` and `udt`). Decide that before porting any of them.
- Every rewrite in the original is guarded by an exact-reprint or checked-arithmetic test. Keep the same guard: a rewrite that cannot be shown to print the same value must leave the expression alone.
