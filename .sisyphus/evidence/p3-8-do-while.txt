P3-8: Do-while loop recovery improvement
=========================================

Changes:
- crates/unlace-struct/src/structurer.rs

Improvements:
1. find_loop_exit(): Now finds exits for do-while loops by checking latch
   successors. Previously only checked header successors, which missed
   do-while exits because the header dominates everything in that CFG shape.

2. try_structure_loop() do-while branch: Added validation that the latch
   CBRANCH has both a back-edge to header AND an exit edge. Falls back to
   while(true) if the pattern doesn't match, preventing misclassification.

3. Added 3 new tests:
   - test_do_while_basic: Verifies BB0→BB1(latch CBRANCH) → DoWhile node
   - test_do_while_vs_while: Builds both loop types, verifies While vs DoWhile
   - test_do_while_exit_found: Verifies post-loop code is structured after do-while

Detection criteria:
- Loop has back-edge from latch → header
- Header block has NO CBRANCH (no conditional exit)
- Latch block has CBRANCH: one successor is header (back-edge), other exits
- → emit `do { body } while (cond);`
