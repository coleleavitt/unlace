P5-25: Short-circuit boolean recovery (a && b, a || b)
======================================================

NEW FILE: crates/unlace-struct/src/short_circuit.rs

Algorithm:
  - Post-structuring HIR pass (same pattern as ternary_recovery.rs)
  - Top-down pattern matching on nested If nodes
  - && pattern: If(a) { If(b) {T} else {F} } else {F} → BoolAnd(a,b)
  - || pattern: If(a) {T} else { If(b) {T} else {F} } → BoolOr(a,b)
  - Chained patterns collapse via recursive try_collapse (a && b && c)
  - Emits synthetic Statement(IrInsn{BoolAnd/BoolOr}) + merged If
  - Synthetic varnodes use unique-space at high offsets (0xFFFE_0000+)
  - Adds synthetic varnodes to foldable_exprs for C printer inlining

Module registered in crates/unlace-struct/src/lib.rs:
  - pub mod short_circuit;
  - pub use short_circuit::short_circuit_recovery;
