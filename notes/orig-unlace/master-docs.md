# origin/master docs/: techniques the archived engine documents that main lacks

Scope: the 117 files under `docs/` on origin/master (3aaf121866). Most are handoffs, batch logs, plans and gap lists. I read the 22 that describe techniques, then checked each claim against the master code it names and against origin/main (517a594ef9). Anything already in `notes/archived-master-inventory.md` (signed releases, fuzz harness, anti-debug, packer identification, plugin SDK, CFG DOT, quality scorecard, Rocq proofs, Lumina extras) is not repeated here. MCP, debugger, emulator, LSP and hand-written lifters are out of scope.

## Checked and not listed

- Intel HEX and Motorola S-record: main ahead (`crates/unlace-analysis/src/loader/firmware/containers.rs:56-61`). Master has no S-record loader.
- ESP32 images: main has them (`crates/unlace-analysis/src/loader/firmware/esprom.rs`).
- DWARF frame-base offset (CFA versus frame pointer): main has it (`crates/unlace-analysis/src/analyzers/dwarf/dwarfscopes.rs:4-30`, `Cfa` variant). The +16 calibration in `docs/design-lvar-recovery-spec-2026-06-04.md` is covered by that path.
- Node split, Tarjan irreducibility, interning of core types, determinism charter: main has them (node split and Tarjan are cited in row 4).
- Dyld chained fixups and subcache names: main has them (`crates/unlace-analysis/src/loader/dyldcache.rs:411`, `loader/format/macho/chained.rs`).
- FLIRT: main has scored matching (`crates/unlace-analysis/src/analyzers/flirt/mod.rs:263-305`). The items in `docs/flirt.md` "Not implemented" (names at non-zero offsets, tail bytes against relocations, alignment-padding retry) were not verified either way.
- Lua bytecode chunk parser (`crates/unlace-lift-lua/src/chunk.rs`): a hand-written lifter, out of scope.
- rustc-style widening and narrowing (`docs/rustc-techniques.md`): a recommendation only. Master has no such code either.
- Canary-read counter (`crates/unlace-cli/src/main.rs:1673`, `__readfsqword`): a quality counter. Main has no equivalent, but it sits under the quality scorecard already listed in the inventory.
