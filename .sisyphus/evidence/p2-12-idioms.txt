P2-12 Idiom Recognition — Evidence
===================================

Created: crates/unlace-passes/src/idiom_recognition.rs
Updated: crates/unlace-passes/src/lib.rs (pub mod + pub use)

Patterns implemented:
  1. INT_XOR(v, v)        → COPY 0   (self-zeroing)
  2. INT_SUB(v, v)        → COPY 0   (self-zeroing)
  3. INT_AND(v, all_ones)  → COPY v   (identity mask, commutative)
  4. INT_OR(v, 0)          → COPY v   (additive identity, commutative)
  5. INT_ADD(v, 0)         → COPY v   (additive identity, commutative)
  6. INT_MUL(v, 1)         → COPY v   (multiplicative identity, commutative)
  7. BOOL_AND(v, v)        → COPY v   (idempotent)
  8. BOOL_OR(v, v)         → COPY v   (idempotent)

Design notes:
  - Compares inputs via full Varnode equality (space + offset + size)
  - Skips const-const operands (defers to ConstantFoldPass)
  - All-ones detection: mask_for_size(size) matches input offset
  - Fixed-point iteration loop inside run()
  - No HashMap used (lint-determinism passes)
