P4-23: CALLOTHER resolution to intrinsic names
================================================

Implementation:
- Added `callother_intrinsic_name()` function mapping numeric tags to C intrinsic names:
  - String ops: 0x1→__builtin_memcpy, 0x2→__builtin_memset, 0x3→__builtin_memcmp
  - SSE moves: 0x100→_mm_load_si128, 0x101→_mm_loadu_si128
  - SSE arith: 0x110-0x113→_mm_add_epi{8,16,32,64}
  - SSE sub: 0x118-0x11B→_mm_sub_epi{8,16,32,64}
  - SSE logic: 0x120→_mm_and_si128, 0x121→_mm_or_si128, 0x122→_mm_xor_si128
- Added `emit_callother()` function:
  - Reads tag from inputs[0] (constant)
  - Known tag: emits `intrinsic_name(arg1, arg2, ...)` 
  - Unknown tag: emits `/* CALLOTHER N */ 0`
  - Dynamic/missing tag: emits appropriate fallback
- Handled both output (emit_expr) and no-output (emit_statement) paths

Tests added:
- test_callother_resolved: PADDB tag → _mm_add_epi8() 
- test_callother_unknown_annotated: unknown tag → /* CALLOTHER 57005 */
- test_callother_no_output_resolved: store-form MOVDQA → _mm_load_si128()

All 973 workspace tests pass.
