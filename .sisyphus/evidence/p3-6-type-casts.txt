P3-6: IDA-style type casts (_QWORD *, _DWORD *, _BYTE *)
=========================================================

Date: 2026-04-29

Changes:
  - crates/unlace-output/src/c_printer.rs
    - Added IDA_TYPEDEFS constant with 8 typedefs (_BYTE, _WORD, _DWORD, _QWORD,
      __int8, __int16, __int32, __int64)
    - Typedefs emitted at top of every print_c output
    - Added ida_ptr_type() — maps access size to IDA pointer cast name
    - Updated LOAD emission: *(void **)(addr) → *(_QWORD *)(addr) for 8-byte,
      *(_DWORD *) for 4-byte, *(_WORD *) for 2-byte, *(_BYTE *) for 1-byte
    - Updated STORE emission: same pattern
    - Updated type_for_size(): uses __int64/__int32/__int16/__int8 for signed,
      unsigned __int64/etc for unsigned (IDA style)
    - Updated infer_type_from_insn(): Load output is UnsignedInt(size) not Ptr
    - Updated existing test_struct_field_no_match to expect *(_DWORD *)

Tests (8 new):
  test_type_casts_qword_load   — 8-byte LOAD → *(_QWORD *)
  test_type_casts_dword_load   — 4-byte LOAD → *(_DWORD *)
  test_type_casts_byte_load    — 1-byte LOAD → *(_BYTE *)
  test_type_casts_word_load    — 2-byte LOAD → *(_WORD *)
  test_type_casts_typedefs_in_output — all 8 typedefs present, before function
  test_type_casts_signed_int64_cast  — IntSext 4→8 uses (__int64)
  test_type_casts_unsigned_zext      — IntZext 4→8 uses (unsigned __int64)
  test_type_casts_compiles           — gcc -fsyntax-only passes on typed output
