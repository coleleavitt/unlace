Algorithm (RetDec-style):
  1. Build def_map: SsaVarnode → IrInsn from SsaFunction var_map
  2. Walk HIR looking for if-else-if chains (HirNode::If with else_body containing another If)
  3. For each condition, extract IntEqual(expr, Const) via def_map lookup
  4. Verify same base Varnode across all conditions in the chain
  5. Reject side-effecting expressions: RAM-space operands, Call/Callind/Callother/Load defines
  6. Require ≥ 3 cases (MIN_CASES = 3)
  7. Convert to HirNode::Switch { cond, cases: Vec<(SwitchCase::Value, body)>, default }
  8. Final else clause becomes default case

Pipeline integration:
  - Runs after ternary_recovery, before C emission
  - Called in pipeline.rs: unlace_struct::if_chain_to_switch(&mut hir, ssa)

  test_if_chain_2_cases_no_convert       — 2 cases (below threshold) → stays if-else
