P4-11: Global variable naming
=============================

Implementation in crates/unlace-output/src/c_printer.rs:

1. Added `try_global_var_name()` helper:
   - Checks if address varnode is Const with value > 0x10000 (GLOBAL_ADDR_THRESHOLD)
   - First checks `ctx.symbols` for a symbol name at that address
   - Otherwise generates IDA-style name: byte_XXXX, word_XXXX, dword_XXXX, qword_XXXX
   - Where XXXX is uppercase hex address

2. Integrated into LOAD expression emission (emit_expr_with_prec, IrOp::Load arm):
   - Checks before struct field resolution and pointer cast fallback
   - Returns global name directly instead of *(cast)(addr)

3. Integrated into STORE statement emission (emit_statement, IrOp::Store arm):
   - Checks before struct field resolution and pointer cast fallback
   - Emits `global_name = val;` instead of `*(cast)(addr) = val;`
