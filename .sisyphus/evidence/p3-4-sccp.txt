P3-4: Sparse Conditional Constant Propagation (SCCP)
=====================================================

Implementation: crates/unlace-passes/src/sccp.rs
Module registered: crates/unlace-passes/src/lib.rs (pub mod sccp; pub use sccp::SccpPass;)

Algorithm (Wegman & Zadeck 1991):
- Three-valued lattice: Top (uninitialized) → Constant(value, size) → Bottom (overdefined)
- Two worklists: CFG edges (block reachability) and SSA edges (def-use propagation)
- Entry block seeded as reachable; external inputs (undefined registers) initialized to Bottom
- CBRANCH with constant condition: only feasible successor edge added
- Phi nodes: meet of all reachable input values (unreachable predecessors skipped)
- Rewrite phase: replace Constant outputs with COPY of literal; Top in reachable blocks → COPY 0

Data structures (BTreeMap/BTreeSet per lint):
- values: BTreeMap<SsaVarnode, LatticeValue> — lattice state per SSA variable
- reachable: BTreeSet<BlockId> — which blocks are reachable
- uses: BTreeMap<SsaVarnode, Vec<(BlockId, usize)>> — def-use chains for instructions
- phi_uses: BTreeMap<SsaVarnode, Vec<(BlockId, SsaVarnode)>> — def-use chains for phi nodes

Pass trait: SccpPass implements Pass { name: "sccp", run: solve + rewrite }
