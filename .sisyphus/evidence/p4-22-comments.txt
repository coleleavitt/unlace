P4-22: Register/stack variable comments in declarations
========================================================

WHAT CHANGED
------------
- crates/unlace-output/src/c_printer.rs:
  - Variable declaration loop (line ~207) now emits IDA-style location comments
  - Added `varnode_location_comment()`: maps Varnode space to comment string
    - SpaceId::Register → register name (e.g., "rax", "ecx", "xmm0")
    - SpaceId::Stack → "[rsp+XXh]" format
    - SpaceId::Unique → "temp"
    - SpaceId::Const/Ram → None (no comment)
  - Added `x86_64_register_name()`: full offset+size → name mapping for:
    - GP registers (RAX..R15 at all widths: 64/32/16/8-bit)
    - High bytes (AH, BH, CH, DH)
    - RFLAGS (CF, PF, AF, ZF, SF, OF)
    - XMM0-XMM15 (128-bit) and YMM0-YMM15 (256-bit)

- crates/unlace-output/src/ir_dump.rs:
  - Fixed pre-existing missing fields (inferred_params, inferred_return_type)

- crates/unlace-passes/src/lib.rs:
  - Removed pre-existing broken re-exports (ParamInferPass, ReturnTypeInferPass)
