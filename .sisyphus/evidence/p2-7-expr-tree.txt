### Side-effecting ops NEVER folded
STORE, LOAD, CALL, CALLIND, BRANCH, CBRANCH, BRANCHIND, RETURN, NEW, CALLOTHER, CPOOLREF, INDIRECT, MULTIEQUAL

### Safety constraints
- Only folds single-use outputs (use_count == 1 from all consumers)
- Uses from control-flow conditions and return values count toward use_count
- Only folds when definition and consumer are at the same nesting depth
- Phi nodes (MULTIEQUAL) never folded
