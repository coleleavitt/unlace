# P3-15: .eh_frame parsing for FDE function bounds and exception edges
# Evidence — 2026-04-29

## Files Changed
- Created: crates/unlace-loader/src/eh_frame.rs (new module)
- Modified: crates/unlace-loader/src/lib.rs (added `pub mod eh_frame` and re-exports)

## Implementation Summary
- Parse .eh_frame section using gimli::EhFrame + gimli::UnwindSection trait
- Extract FDE function extents (start/end virtual addresses) into BTreeMap<u64, FunctionExtent>
- Extract LSDA pointers from FDE augmentation data into Vec<LsdaEntry>
- Graceful handling of missing .eh_frame (returns empty)
- Graceful handling of corrupt data (logs warning, returns partial results, no panic)
- CIE caching by offset for efficient re-parsing
- Base address configuration (.eh_frame, .text, .got, .eh_frame_hdr) for correct PC-relative decoding

## Public API
- EhFrameInfo { function_extents: BTreeMap<u64, FunctionExtent>, lsda_entries: Vec<LsdaEntry> }
- FunctionExtent { start: u64, end: u64 }
- LsdaEntry { lsda_addr: u64, function_start: u64 }
- parse_eh_frame(image: &BinaryImage) -> Result<EhFrameInfo, LoadError>
