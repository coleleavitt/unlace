# Structurer techniques on origin/master vs main

Scope: `origin/master:crates/unlace-struct/src/structurer/` (mod.rs 5,767 lines, dominator.rs 1,094, trace.rs 246, tests.rs 3,308). Where the structurer calls into sibling modules that carry the technique (reaching_conditions.rs, condition_refinement.rs, irreducible.rs, node_split.rs), those are cited too. Read with `git show origin/master:<path>`; nothing was checked out, built or run.

Main structures with the region structurer (Phoenix/SAILR port, `crates/unlace-structure/src/p8_structure/region_structurer.rs`, default on via `regionstructure`, `docs/spec/08-structuring.md` 8.2) and the goto-quality family (8.3). Most of the archive's per-pattern work (loops, switches, for-loops, `?:`, goto cleanup) is on main in another form, so the table marks those "have". The real gaps are three algorithms: a dominator-tree emitter, a second-opinion choice by goto count, and DREAM-style condition refinement for irreducible regions. The archive's own tests also have a randomized CFG-equivalence check that main lacks.

Ranking is by value for the cost. Size: S under about 300 lines, M about 300 to 1,000, L over 1,000.
