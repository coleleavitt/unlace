# Original unlace: remaining pass techniques (crates/unlace-passes)

Scope: the `crates/unlace-passes/src/` files on `origin/master` (archived engine, 194 files) that are not covered by the idiom, algebra, variable, SCCP, calling-convention, stack-frame, type-inference or object-widen notes. Main status is read from code on `origin/main`, not from comments; `file:line` is the main file that does the work. Read-only: `git show` and `git grep`; nothing was built or run.

Size is the master file length: S under 300 lines, M 300 to 700, L over 700. "Wired" means a pass is listed in `crates/unlace-cli/src/pipeline.rs` on master; "unwired" means only `lib.rs` exports it.

## Skip

- **Dead on master (no caller at all):** `abi_layout.rs` (350 lines, `compute_record_layout`), `lazy_lift.rs`, `protobuf_recognize.rs`. Do not port without a caller.
- **Optimizers a decompiler should not run:** `licm.rs`, `gvn.rs`, `cse.rs`, `iv_elim.rs`, `strength_reduce.rs`, `jump_threading.rs`, `dse_global.rs`, `memory_ssa_dse.rs`. Hoisting or strength-reducing a loop removes the source shape that the printer should keep.
- **Needs an SMT solver:** `path_sensitive.rs` (Z3-style), `symbolic_heap.rs`. Main has no solver dependency.
- **Coverage and fuzzing:** `coverage_ingest.rs`, `diff_coverage.rs`, `symex_coverage.rs`, `qemu_tcg.rs`. Out of scope (emulator and fuzzer tier).
- **Other owners:** `type_vote`, `interproc_types`, `whole_prog_type_unify.rs`, `caller_param_propagate.rs` are type work and sit with the type notes; `call_args.rs`, `indirect_*` and `switch_table_recovery.rs` are covered by main's call and jump-table recovery.
