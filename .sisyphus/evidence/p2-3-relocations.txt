=========================================================

PLT Resolution Strategy:
1. Iterate object::Object::dynamic_relocations() for all dynamic relocs.
2. Classify each reloc by r_type (JUMP_SLOT, GLOB_DAT, RELATIVE, Other).
3. Resolve symbol names via dynamic symbol table (dynsym), falling back to symtab.
4. For JUMP_SLOT entries, correlate with .plt.sec (IBT-enabled) or .plt section
   to compute stub virtual addresses: base + (index * 16).
5. .plt.sec has no PLT0 stub; .plt has a 16-byte PLT0 stub before entries.
