## Detection logic

- `classify_panic()` matches both demangled and mangled Rust symbol names:
  - core::panicking::panic / _ZN4core9panicking5panic* → PanicKind::Panic
  - core::panicking::panic_fmt → PanicKind::Panic
  - core::panicking::panic_bounds_check → PanicKind::BoundsCheck
  - core::result::unwrap_failed / _ZN4core6result13unwrap_failed* → PanicKind::UnwrapFailed
  - core::option::expect_failed / _ZN4core6option13expect_failed* → PanicKind::ExpectFailed
  - std::process::abort / _ZN3std7process5abort* → PanicKind::Abort

## C printer integration

- When emitting CALL/CALLIND instructions, checks `ctx.panic_sites` by instruction address
- Emits `/* PANIC: <kind> */` comment before the call statement
