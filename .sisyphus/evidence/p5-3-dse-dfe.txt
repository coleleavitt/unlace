P5-3: Enable DeadStoreElim + DeadFlagElim
============================================

Change: Added DeadStoreElimPass and DeadFlagElimPass as single-run passes
after the fixedpoint loop in pipeline.rs.

Added after fixedpoint loop:
  DeadStoreElimPass.run(ssa).context("dead store elimination failed")?;
  DeadFlagElimPass.run(ssa).context("dead flag elimination failed")?;

Imports added: DeadStoreElimPass, DeadFlagElimPass

These passes run once after the fixedpoint loop stabilizes because:
- DeadStoreElim removes stores to memory that are never read, which only
  needs to run once after all constants/copies are propagated
- DeadFlagElim removes flag computations whose results are never used,
  which similarly benefits from running after copy prop/DCE finish

Test results:
  Baseline: 995 passed, 0 failed
  After DSE+DFE: 995 passed, 0 failed
  No regressions.
