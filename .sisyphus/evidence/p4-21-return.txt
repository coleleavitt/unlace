P4-21: Return type inference
============================

Implementation:
- Extended crates/unlace-passes/src/calling_convention.rs with:
  - ReturnTypeInferPass: detects return type from RETURN instruction analysis
  - Scans backwards from RETURN to find last write to RAX or XMM0
  - No RAX/XMM0 write → PrimitiveType::Unknown (void in C output)
  - XMM0 write → Double
  - RAX write with float op → Double
  - RAX write with comparison → Bool
  - RAX write, size 4 → Int(4)
  - RAX write, size 8 → Int(8) (default)

- Updated C printer (crates/unlace-output/src/c_printer.rs):
  - Added c_return_type() function: Unknown → "void", others delegate to c_type()
  - Function signature now uses c_return_type() for return type display

Tests added (all pass):
- test_return_void: no RAX write before RETURN → Unknown (void)
- test_return_int64: RAX written with IntAdd → Int(8) (long long)
- test_return_int32: EAX written (4-byte) → Int(4) (int)
- test_return_bool_from_comparison: RAX from IntEqual → Bool (_Bool)
- test_return_double_from_float_op: XMM0 from FloatAdd → Double (double)

Verified: cargo test --workspace passes (993+ tests, 0 failures)
