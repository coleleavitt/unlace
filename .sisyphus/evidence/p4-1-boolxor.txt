P4-1: Fix BoolXor + IntNegate + BoolNegate semantic bugs in C printer
======================================================================

Date: 2026-04-29

Bugs Fixed
----------
1. BoolXor: was emitting "!=" (logical not-equal), now emits "^" (bitwise XOR)
   - Line 1015 of c_printer.rs
   - In C, boolean XOR is correctly expressed as `^`, not `!=`.
     While `!=` is equivalent for single-bit booleans, `^` is the
     canonical XOR operator and correct for multi-bit operands.

2. IntNegate: was emitting "!" (logical NOT), now emits "~" (bitwise NOT)
   - Line 1026 of c_printer.rs
   - `!` is logical NOT (returns 0 or 1). `~` is bitwise NOT (flips all bits).
     INT_NEGATE is bitwise complement, not logical negation.

Verified Correct (no change)
----------------------------
3. BoolNegate: correctly emits "!" (logical NOT) — line 1027
4. Int2comp: correctly emits "-" (two's complement negation) — line 1028
