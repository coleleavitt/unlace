P4-13: Add Break to HIR
=======================

Changes:
- Added `Break` variant to `HirNode` enum in hir.rs
- Updated ALL match arms across 4 files:
  - structurer.rs: recover_for_loops_in_children, node_references_varnode
  - c_printer.rs: collect_varnodes, emit_node
- Added `Break` emission in c_printer: emits `break;\n`
- Implemented loop exit detection in structurer:
  - `collect_loop_blocks()`: computes natural loop body via reverse traversal from latches
  - `structure_loop_body_inner()`: checks if a block is outside the loop body → emits Break
- 2 new tests:
  - test_break_in_while_loop: while(true) with conditional exit → Break in output
  - test_break_replaces_goto_to_exit: exit edge produces Break, not Goto

Test results: 970 tests, 0 failures (baseline was 949+)
No regressions.
