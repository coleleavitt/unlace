P4-24: Constant folding cleanup in C output
=============================================

Implementation in emit_expr_with_prec:
- IntXor: if inputs[0] == inputs[1] and both are non-const → emit "0" (XOR-self)
- IntAnd: if inputs[1] is const 0 → emit "0" (AND with zero)
- IntOr: if inputs[1] is const 0 → emit inputs[0] (OR with zero identity)
- Popcount: if inputs[0] is const 0 → emit "0" (popcount of zero)
