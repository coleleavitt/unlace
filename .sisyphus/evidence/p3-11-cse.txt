P3-11 — Common Subexpression Elimination (CSE)
================================================

TASK
----
Implement dominator-tree-based CSE pass in unlace-passes:
  * file:   crates/unlace-passes/src/cse.rs   (NEW)
  * lib.rs: pub mod cse; pub use cse::CsePass;
  * algo:   walk SSA function in dominator-tree pre-order, hash each
            eligible instruction by (op, ordered SSA inputs), replace
            duplicates with COPY of the earlier dominating result.
  * lints:  BTreeMap only (no HashMap), determinism preserved.

ALGORITHM
---------
Cooper & Torczon §8.6.1 (Engineering a Compiler) — scoped dominator-tree
walk.  An expression-table BTreeMap<CseKey, SsaVarnode> is grown when
entering a block and pruned when leaving the dominator subtree, so a
later occurrence is only matched against earlier definitions that
strictly dominate it.

Eligible opcodes (pure):
  INT_{ADD,SUB,MULT,DIV,SDIV,REM,SREM},
  INT_{NEGATE,2COMP,ZEXT,SEXT},
  INT_{AND,OR,XOR,LEFT,RIGHT,SRIGHT},
  INT_{EQUAL,NOTEQUAL,LESS,LESSEQUAL,SLESS,SLESSEQUAL,CARRY,SCARRY,SBORROW},
  BOOL_{NEGATE,AND,OR,XOR},
  PIECE, SUBPIECE, POPCOUNT, LZCOUNT.

Skipped (impure / side-effecting / control flow):
  LOAD, STORE, CALL, CALLIND, CALLOTHER, NEW, CPOOLREF, INDIRECT,
  BRANCH, CBRANCH, BRANCHIND, RETURN, MULTIEQUAL.

Commutative ops with sorted operand keys:
  INT_ADD, INT_MULT, INT_AND, INT_OR, INT_XOR,
  INT_EQUAL, INT_NOTEQUAL, INT_CARRY, INT_SCARRY,
  BOOL_AND, BOOL_OR, BOOL_XOR.
