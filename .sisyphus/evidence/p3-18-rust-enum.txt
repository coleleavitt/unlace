Detection Logic
---------------
1. find_discriminant_loads: scans all LOAD instructions for offset-0 loads with output size 1/2/4/8
2. is_offset_zero: checks if address is bare register/unique/stack OR defined by INT_ADD(base,0) / PTRADD(base,0,...) / COPY
3. find_comparisons: scans all INT_EQUAL instructions, maps SSA varnode → constant comparisons
4. Main pass: for each load, collects all comparisons against its SSA varnode; requires 2+ distinct constants
5. Builds EnumDiscriminant with Variant_{value} naming, stores in function.enum_discriminants
