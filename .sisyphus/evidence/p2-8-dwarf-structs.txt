P2-8: DWARF struct/enum/union recovery — EVIDENCE
===================================================

Date: 2026-04-29

## What was implemented

1. New types in crates/unlace-loader/src/dwarf.rs:
   - StructType { name, size, fields: Vec<StructField> }
   - StructField { name, offset, size, type_name }
   - EnumType { name, size, variants: Vec<(String, i64)> }
   - UnionType { name, size, members: Vec<StructField> }

2. Extended DwarfInfo with:
   - structs: BTreeMap<String, StructType>
   - enums: BTreeMap<String, EnumType>
   - unions: BTreeMap<String, UnionType>

3. Implemented parsing of:
   - DW_TAG_structure_type with DW_TAG_member children
   - DW_TAG_enumeration_type with DW_TAG_enumerator children
   - DW_TAG_union_type with DW_TAG_member children
   - DW_AT_data_member_location for field offsets
   - DW_AT_byte_size from member or referenced type DIE
   - DW_AT_const_value for enum variant values

4. Updated re-exports in lib.rs
