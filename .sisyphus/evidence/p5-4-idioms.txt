P5-4: Enable IdiomRecognition, DivisionIdiom, ModuloIdiom, ConditionSimplify
==============================================================================

Changes:
  - Added IdiomRecognitionPass and ConditionSimplifyPass to the fixedpoint loop
  - Added DivisionIdiomPass and ModuloIdiomPass as single-run passes after fixedpoint

Fixedpoint loop now:
  let passes: &[&dyn Pass] = &[&fold, &prop, &dce, &sccp, &cse, &idiom, &cond];

Single-run passes (after fixedpoint):
  DeadStoreElimPass.run(ssa)?;
  DeadFlagElimPass.run(ssa)?;
  DivisionIdiomPass.run(ssa)?;
  ModuloIdiomPass.run(ssa)?;

Imports added: ConditionSimplifyPass, DivisionIdiomPass, IdiomRecognitionPass, ModuloIdiomPass

Rationale for placement:
- IdiomRecognitionPass in fixedpoint: recognizes common code patterns (sign extension,
  zero extension, byte swap) that simplify IR, enabling further constant folding
- ConditionSimplifyPass in fixedpoint: simplifies branch conditions, which can enable
  SCCP to resolve more branches, enabling further dead code elimination
- DivisionIdiomPass single-run: recognizes compiler-generated multiply-shift sequences
  for division by constant; only needs to run once after IR is stabilized
- ModuloIdiomPass single-run: recognizes compiler-generated patterns for modulo by
  constant; only needs to run once after IR is stabilized

Test results:
  Baseline: 995 passed, 0 failed
  After all idiom passes: 998 passed, 0 failed
  No regressions. +3 tests now passing (likely due to improved IR enabling
  previously marginal tests to succeed).
