5. KEY WINS
-----------
1. GOTO ELIMINATION: medium.c 13→0 gotos. The label hoisting + condition
   duplication + label cleanup pipeline completely solved the cross-scope
   goto problem that had plagued medium.c since Phase 1.

2. CMOVcc LIFTING: All 12 x86 CMOVcc variants now emit proper conditional
   diamond CFGs instead of unconditional copies. This recovered ~10pp on
   debug_calls.

3. cpp_rtti BREAKTHROUGH: +36.4pp improvement from the same goto
   elimination passes. The cross-branch goto pattern was identical to
   medium.c's, so the fix generalized perfectly.

4. ZERO REGRESSIONS: No fixture dropped even 0.1pp. All improvements
   were purely additive.
