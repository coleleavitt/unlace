P4-20: Parameter type inference from calling convention registers
================================================================

Implementation:
- Extended crates/unlace-passes/src/calling_convention.rs with:
  - ParamInferPass: detects parameter count and types from register usage
  - SystemV: RDI=a1, RSI=a2, RDX=a3, RCX=a4, R8=a5, R9=a6; XMM0-XMM7 for float
  - MicrosoftX64: RCX=a1, RDX=a2, R8=a3, R9=a4; XMM0-XMM3 for float
  - Type inference: float ops → double, pointer ops → Ptr, else → Int(8)
  - Consecutive register detection: stops at first unused register

- Added to SsaFunction (crates/unlace-ir/src/ssa.rs):
  - inferred_params: Vec<(String, PrimitiveType)>
  - inferred_return_type: PrimitiveType

- Updated structurer (crates/unlace-struct/src/structurer.rs):
  - Copies inferred_params and inferred_return_type to HirFunction

- Updated pipeline (crates/unlace-cli/src/pipeline.rs):
  - Added CallingConventionDetectPass, ParamInferPass, ReturnTypeInferPass to pass pipeline

Tests added (all pass):
- test_param_count_sysv: SystemV function using RDI+RSI → 2 params detected
- test_param_count_zero: function not reading any param registers → 0 params
- test_param_ptr_type: RDI used in Load → param typed as Ptr
- test_param_six_sysv: all 6 SysV registers → 6 params detected
- test_param_msx64_four: 4 MSX64 registers → 4 params detected

Verified: cargo test --workspace passes (993+ tests, 0 failures)
