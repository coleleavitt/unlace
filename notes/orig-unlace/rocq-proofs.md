# From original unlace: Rocq proof suite (rocq-tests/)

Source: `origin/master` `rocq-tests/` (45 `.v` theories under `theories/`, extraction under `extraction/`, COVERAGE.md, README.md; about 336 KB). Read with `git show`, nothing checked out. The proofs were not re-checked here (no `coqc` or unlace binary run). What I did verify: no `Admitted`, `admit` or `Axiom` appears in any theory file, and about 389 named `Theorem`/`Lemma`/`Corollary` statements exist. Every theorem closes with `Qed`.

Main status is checked against `origin/main` (188480126a). Main has no Rocq or Coq files, no `scripts/verify_proofs.sh`, and no `docs/formal-verification.md`. No `Cargo.toml` on main or master depends on `proptest`, `quickcheck`, `arbitrary` or `bolero`, so main has no property-test harness. Master's conformance tests (`crates/unlace-ir/tests/{coq_conformance,tinfo_conformance,dominator_conformance,layout_conformance,extraction_oracle}.rs`) target the removed `unlace-ir` crate and are not on main.

The point of this note: the proofs state invariants that could run as cheap checks on main, with no Coq toolchain. Several are exhaustive at small widths, so they are real tests, not samples. Ranking favours checks that would catch wrong output, and the two rows marked "no" are research framing, not code.

Status legend: **have** (implemented, invariant not checked), **partial** (related code, invariant or domain missing), **missing**.

## What is novel on master (and not on main)

- Exhaustive small-width checks (rows 1-3) are the cheapest real verification here. They need no new dependency, since main has no property-test crate and the checks can use a seeded generator.
- Rows 4-8 turn comments already in main into tests. Row 4 is the strongest match to a documented claim (`flowmode.rs:47`).
- Master's own README calls the proofs a "lead over IDA/Ghidra". That claim is not checked here, and it does not bear on whether a check is worth porting.

## Not ported, on purpose

- The Rocq project, its Makefile and `scripts/verify_proofs.sh`. Main does not need the Coq toolchain for the checks above.
- The conformance tests for master's `unlace-ir` crate. The crate is gone and its types do not match main.
- The Galois-connection and principal-type framing (rows 14-16) as code.
