=== P9-24: JUMPOUT() + MEMORY[addr] annotations ===

Implemented:
- emit_statement: IrOp::Branchind \u2192 'JUMPOUT(<target>);' when no
  structurer-resolved label exists. Resolves the target operand
  through the standard operand-resolution pipeline.
- IrOp::Load fallback path: try_emit_memory_annotation gates on
  const-space input not in the string table; emits 'MEMORY[0x<addr>]'.

Prelude additions:
- #define MEMORY ((volatile unsigned char *)0)   // gcc-syntactic
- #define JUMPOUT(addr) ((void)(addr))           // gcc-syntactic no-op

Scope limitation (documented):
- try_emit_memory_annotation runs AFTER try_global_var_name, which
  synthesizes 'qword_<addr>' for any const address. So MEMORY[] is
  currently reachable only when global-var synthesis declines (rare).
  Full IDA semantics ('addr not in any loaded section') would need
  section-presence info plumbed into PrintCtx \u2014 deferred.

Tests:
- test_branchind_emits_jumpout (new) \u2014 hand-built BRANCHIND HIR
  asserts JUMPOUT() in output.
- All 180 c_printer tests pass under gcc -fsyntax-only.
