# Original unlace Windows loader and PDB/RTTI/SEH techniques vs main

Scope: `origin/master` `crates/unlace-loader/src/{pe.rs, pdb_types.rs, rtti.rs, seh.rs}` (3,313 + 3,021 + 1,165 + 930 lines), compared against main's PE, PDB, RTTI and SEH code under `crates/unlace-analysis/src/`. Read only: no code was built or run. Checked against `origin/main`. The existing `notes/archived-master-inventory.md` does not cover these four files, so this is the first row-by-row comparison of them.

Status key: **have** = main implements it (file:line); **partial** = main has a narrower version; **missing** = no equivalent found by search. Master paths are on `origin/master`.
