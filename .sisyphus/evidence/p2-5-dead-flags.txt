## Design

- Flag varnodes identified by: SpaceId::Register && offset >= 256
  (matching CF=256, PF=257, AF=258, ZF=259, SF=260, OF=261 from
  crates/unlace-lift-x86/src/register_file.rs)
- Pass only removes instructions whose output is an unused flag varnode.
  Non-flag dead code is untouched (that's DCE's responsibility).
- Compaction logic mirrors dce.rs: re-keys var_map entries after removal.
- Uses BTreeSet only (no HashMap).
